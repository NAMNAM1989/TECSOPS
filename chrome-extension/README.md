# TECSOPS — Chrome extension Kho TECS-TCS ESID

Channel: `tecsops-tcs-ext`. Chỉ Login / Quét / Điền ESID cho kho **TECS-TCS**.

- Kho **TCS**: cài `chrome-extension-tcs` (Chrome profile riêng — cookie tcs.com.vn không tách trong cùng profile).
- Kho **SCSC eCargo**: cài `chrome-extension-scsc`.

## Cài

Load unpacked thư mục `chrome-extension`.
