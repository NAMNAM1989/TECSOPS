# TECSOPS — Chrome extension Kho TCS ESID

Channel: `tecsops-tcs-direct-ext`. Phục vụ mã kho dữ liệu **TCS** và **TECS-TCS**. Một trong **hai** Ext chuẩn (cùng `chrome-extension-scsc`).

Protocol Ops↔Ext: xem `docs/ops-ext-protocol.md` (`EXT_READY` / `PING`→`PONG` / job / result / error).

Cặp với Ext SCSC. Nếu còn Ext TECS-TCS cũ (`tecsops-tcs-ext`) trên máy — gỡ unpacked đó, chỉ giữ Ext TCS + Ext SCSC.
