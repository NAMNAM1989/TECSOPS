- Lô Volume TR517 `618-5667 5835` (TECS-SCSC): 102 kiện / 1125 kg / DIM **1089**. Cộng 11 dòng (cắt 3 số lẻ) = 1088.916 → làm tròn 1 kg = 1089. Chargeable = cân thực vì 1089 < 1125. Badge SCSC bị cắt chữ (`Tổng: Để 3` thay vì `làm tròn 1`).
