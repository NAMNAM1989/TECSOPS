# TECSOPS — Chrome extension Kho SCSC eCargo

Đăng ký VCT trên `ecargo.scsc.vn` từ Ops. Channel: `tecsops-scsc-ecargo-ext`.

Một trong **hai** Ext chuẩn (cùng `chrome-extension-tcs`).

Protocol: `docs/ops-ext-protocol.md`.

## Cài

Load unpacked thư mục `chrome-extension-scsc`. Cài song song với Ext TCS ESID nếu cần.
