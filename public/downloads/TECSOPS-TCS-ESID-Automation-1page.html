3. Chi tiết từng bước tự động hóa

Bước Tự động làm gì Ai thực thi Người cần làm Điều kiện / lưu ý
1. Nhập lô Lưu booking Postgres (AWB, chuyến, ngày bay, DIM…) Ops UI + API Tay Sheet / Booking Kho TECS-TCS · AWB đủ 11 số
2. Đồng bộ Login TCS + quét «Hoàn thành tiếp nhận» + cập nhật status Ops Ext ưu tiên · Agent fallback Tay TK/MK lần đầu · CAPTCHA khó Gộp Login + Quét · không còn nút riêng
3. Điền ESID Đổ form KHAI BÁO từ Ops + danh bạ + hồ sơ Người khai/Agent Ext nếu đã login · else Playwright Tay Kiểm tra form Auto Điền · không submit
4. HOÀN TẤT Ext: mở tab · Agent: bấm HOÀN TẤT sau confirm Ops Ext / Playwright Tay Ext: bấm trên TCS Playwright cần confirm trên Ops
5. Tải PDF Tìm phiếu theo AWB → xuất PDF → tải về máy Playwright · GET /docs — Auto Độc lập với Quét · In ESID đã gỡ
6. In PDF — — Tay In từ file Dùng PDF vừa tải

Ai chạy ở đâu

  • Máy kho: Agent headed · Quét/PDF ổn định
  • Chrome người nhập: Ext · Điền + HOÀN TẤT tay
  • Railway: Ops + Postgres + agent headless · API-first

Flags quan trọng

  • TCS_HEADLESS — Railway=1 · máy kho=0 (headed)
  • Không còn noVNC / TCS_VNC
  • Workspace: IDLE → OPENING → NEEDS_LOGIN → SCANNING → READY

Ghi nhớ: Đồng bộ = Login + Quét · Điền ≠ HOÀN TẤT · PDF ≠ Quét · In ESID đã bỏ · dùng «Tải PDF ESID».
