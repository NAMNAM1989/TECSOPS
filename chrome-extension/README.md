# DEPRECATED — Chrome extension Kho TECS-TCS ESID

> **Không dùng Ext này cho cài mới.** Chuẩn Ops hiện tại chỉ khuyến nghị **hai** Ext:
>
> 1. `chrome-extension-tcs` — kho TCS ESID  
> 2. `chrome-extension-scsc` — kho SCSC eCargo  
>
> Menu «Tải Ext» trên Ops **đã ẩn** gói TECS-TCS. Thư mục này giữ lại để không phá cài sẵn / ZIP cũ.

Channel: `tecsops-tcs-ext` (vẫn hiểu handshake `docs/ops-ext-protocol.md`).

Nếu đã cài legacy: có thể tiếp tục PING/Quét/Điền khi Ops chọn kho TECS-TCS; migration sang Ext TCS khi tiện.
